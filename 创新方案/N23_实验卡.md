## 2. 一句话核心假设
LFMN 的重叠空间 patch 精确注意力存在随 patch 面积二次增长的交互成本；用区域空间摘要和完整通道相关性重新分配该预算，可能在扩大区域范围时改善精度—效率折中。尚未证明原 LRSA 冗余或有精度缺陷。

## 3. 源码事实与问题证据
- 原 LRSA：PreNorm→patch attention→残差→patch_reverse→PreNorm ConvFFN→残差；窗口 [16,20,24,28] 两次重复。
- TAB 按内容分组并使用 EMA 全局中心，与空间区域不是同一能力，本版全部保留。
- N21/N22 40轮终点相对 B0 −0.010334/−0.015972 dB；最终权重开关配对净贡献接近零，不能推断训练期间无作用。
- 单全图线性 memory 每头12维的条件 nullspace 反例否定了“全像素输入必然保留更多信息”，不否定全部线性注意力。
- 本候选没有 LFMN PSNR 实证；空间摘要丢失细节、窗口边界、相关输出幅度和通道压缩均是风险。

## 4. 机制与公式
- 仅替换 LRSA 的空间 attention；窗口 [8,16,32,64]×2；base=8。
- 输入/输出 B×48×H×W；原 PreNorm、ConvFFN、TAB、SFML、ESA、decoder 保留。
- DFE 为原坐标空间卷积与通道投影的乘积，48通道拆为 Q/V 各24。
- 每空间head6维、4heads；V 在每个区域摘要到64空间锚；S=(QVdown^T/6+B)Vdown。
- 通道相关用单head24维：C=((Q^T V)/p²)V^T；拼接两路为48维，经原维度输出投影。
- 保留原 patch_divide/patch_reverse 的重叠口径；当 H/W<p 时只在候选路径 replicate pad 到可取 patch 的大小，返回前裁回。
- 相对位置偏置按区域内相对offset平均；生产路径用二维prefix sum，不构造 p²×p² 的临时张量。测试参考限定p≤16。
- 官方 HiT block 与原 LFMN norm 位置不同；本版明确选择 LFMN PreNorm，非忠实整网复现。
- 损失计划 L1；train/eval 使用同一 SCC 算子，无教师、无新状态或额外 loss。
- 替换而非新增第三分支；没有再叠 CCE/CAMD 或新融合 gate。

## 5. 与共同基线的差异
- 删除候选中旧 LRSA attention Q/K/V/proj；换成 DFE+S-SC+C-SC+proj。
- LRSA窗口发生结构变化，训练HR patch仍256；两者不混淆。
- 默认基线文件与共同 trainer/option/data/utility 不修改。
- 初始化不恢复旧 attention 函数；禁止宣传零初始化恢复。关闭诊断以独立原始 B0/reference 实例核验，不保留旧分支来虚报减参。
