# N21/N22 独立候选统一服务器队列

## 范围
从共同基线b198de7打包N21/e649c12、N22/08c2771两个独立模型，不构造N21+N22组合，不覆盖lfmn.py。共享的启动、安全检查和汇总基础设施在本分支统一登记。用户2026-10-07要求顺序N21→N22→B0，并在全部成功后自动关机。

## 固定协议和预算
- 新建B0，从零训练；不使用旧曲线，不要求n9_b0_reuse.tar.gz或历史权重。
- DIV2K训练0001–0800、验证0801–0900；×4、HR256/LR64、batch4、seed1、随机翻转/旋转；ext=img。
- 每组40 epoch，每epoch1000 batch，三组合计120000次更新；这是短筛，不是完整1000 epoch。
- Adam lr2e-4，betas(0.9,0.999)，eps1e-8，weight_decay0；L1；Cosine T_max150、eta_min1e-6，40 epoch截断，不把Cosine周期改成40。
- FP32、关闭TF32、无chop/自集成；全图DIV2K量化RGB PSNR裁边10，共同Y量化SSIM裁边4。不是五benchmark标准Y PSNR。
- 三组在独立进程运行，核验共同参数初值hash、模型初始化后的RNG、每epoch首LR batch裁剪增强hash、配置、数据/源码hash、更新数、逐图完整精度与scheduler状态。
- 总参数上限为基线+2%，三组参数759627/765153/760115。该参数约束不意味着运行等速或显存零增量。
- 单卡GPU0，服务器须至少16GiB显存，推荐RTX4090 24GB；结果盘至少5GiB可用空间，数据存储另计。PyTorch建议2.5+CUDA版；服务器预检查失败不得训练。

## 数据先准备
Git不包含数据。DATA下应有DIV2K/DIV2K_train_HR、DIV2K_train_LR_bicubic/X4、DIV2K_valid_HR、DIV2K_valid_LR_bicubic/X4。
准备阶段逐项核对900对HR/LR并记录hash；实际DataLoader扫描的文件编号也校验，避免额外文件造成切片错位。

## 启动（专用AutoDL市场实例）
```bash
cd /root/autodl-tmp
git clone --branch codex/n21-n22-server-screen https://github.com/LI-mo66/Image-Super-Resolution.git Image-Super-Resolution-N21N22
cd Image-Super-Resolution-N21N22
git log -1 --oneline
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"
command -v nohup setsid flock
python -m pip install einops pillow imageio scikit-image opencv-python-headless matplotlib tqdm
DATA=/root/autodl-tmp/datasets
RUN_DIR="$PWD/experiment/all_runs/n21_n22_40e_seed1_r1"
bash repro/run_n21_n22_screen_server.sh --data-root "$DATA" --output "$RUN_DIR" --prepare-only
```
必须看到PREPARED后才运行后台命令；失败不进入后续启动。输出目录已存在时拒绝覆盖，修复原因后换r2等新目录，不使用--reset。

```bash
nohup setsid bash repro/run_n21_n22_screen_server.sh \
  --data-root "$DATA" --output "$RUN_DIR" --prepared \
  --shutdown-on-success --dedicated-instance \
  > "$RUN_DIR/launcher.log" 2>&1 < /dev/null &
echo $!
tail -F "$RUN_DIR/launcher.log"
```
服务器上的独立session、忽略SIGHUP及重定向stdin/stdout使普通本机关机/SSH断开不影响进程。Ctrl+C只退出tail。不等于服务器重启/宕机后自动续训。

## 完成与风险
- 只有N21/N22/B0均成功，曲线、逐图数据、训练设置和更新数检查通过，summary.json保存、状态保存、os.sync之后，才调用AutoDL官方`/usr/bin/shutdown`。
- NO_GO也属于正常完成，仍关机；程序异常/OOM/数据不足/指标缺失会停止且不关机，保留现场，但会继续产生租用费用，需人工检查和关机。
- 专用实例确认是必要条件。启动和关机前查询其他GPU进程，发现或无法确认时拒绝操作；无法保证识别所有CPU-only/外部服务，禁止与其他任务共用实例。
- AutoDL关机接口调用失败也可能继续计费，最终是否已关机须到控制台核实。本机未实际验证远程关机，不能称已成功关机。
- 关机停止整实例，包括SSH/Jupyter。实例不是释放，结果保留需按平台当前规则及时备份；本地盘不保证永久可靠。
- 正式运行中不要git pull、改代码/数据、重复启动队列。flock防止本checkout重复启动；没有自动续训，不会把半成品当成功。
- N21/N22先跑、B0最后跑意味着前两组无法即时计算净收益；不要与旧B0跨协议比较。

## 首轮闸门
GO候选：final和last5均≥+0.01dB，逐图CI下界>0，中位数>0，胜率≥60%，SSIM差≥−1e-4；仍需效率审计和独立确认，不自动延长。
NO_GO：final与last5均≤0或SSIM差<−1e-4；其余GRAY，不自动追加训练。通过后再补消融、多seed和五benchmark。
