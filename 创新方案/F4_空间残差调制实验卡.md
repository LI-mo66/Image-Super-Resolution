# F4 空间残差调制实验卡

## 1. 身份与授权
F4；结构候选；DECIDED（150e已完成；GRAY参考结果，环境差异限制正式归因）。
分支 codex/f4-spatial-residual-modulation；共同基线 cabc7e4（原始LFMN核心与aa1d65c相同）。
独立实现，不继承F1/F2/F3架构；F3仅为用户要求审计的只读证据。候选提交见Git历史。

## 2. 唯一假设
当前状态的空间信息可能更适合选择本阶段更新R，而不是修改SFML的共享先验瓶颈；是否提高最终PSNR必须端到端检验。没有证实原接入位置是失败根因。

## 3. 证据与反证
原SFML仅读取共享浅层FS，各阶段参数独立。用户F3 epoch20冻结空间探针96图：空间平均/两种shuffle检验集约下降0.056/0.063/0.063dB；只说明该checkpoint依赖空间条件。
统一幅度0.75检验集仅+0.000976dB，CI跨零；不继续幅度搜索。F3对B0 DIV2K终点+0.008215dB，Set14下降且训练GPU不同；不作为已证实架构收益。
未知：残差接入是否更好，额外参数是否主因，多seed、长训、目标GPU延迟。

## 4. 机制与接口
M_i=beta_i(FS)*X_i+gamma_i(FS)
R_i=mid_conv_i(LRSA_i(TAB_i(M_i)))
z_i=LN_channel48(X_i), eps=1e-5, 非仿射、每像素
q_i=Conv1x1(8→48)(DW3x3_8(LeakyReLU(Conv1x1(48→8)(z_i),0.1)))
X_(i+1)=ESA_i(X_i+(1+tanh(q_i))*R_i)
8阶段独立参数；q末层W/b=0；gate初始1，理论范围(0,2)。输入/残差/门控均B48HW，隐藏B8HW，无跨图状态或detach。FP32；全图原尺寸；训练/推理路径相同；损失原L1。
保留原SFML、TAB、LRSA、ConvFFN、ESA与解码。F3 current_correction不存在。原SFML/ESA依然会调制历史特征，不能宣称整个网络只调新增残差。

## 5–6. 差异与最近邻
新增仅8个残差gate，在原始mid_conv之后、ESA之前。保持共同初始化/RNG、训练器、指标实现不变。
SMFANet https://github.com/Zheng-MJ/SMFANet ：当前特征自调制与PCFN；本候选保留LFMN算子、改变阶段更新接入位置。
RCAN https://github.com/yulunzhang/RCAN ：残差通道注意力；本候选用更新前状态产生空间通道gate。
Residual Attention Network https://arxiv.org/abs/1704.06904 ：残差注意力已有先例；零初始化和门控本身不构成新颖贡献。
最简单替代解释是更多参数/通用残差gate。主候选通过后再做等参数残差卷积与条件去除对照，当前不运行。
