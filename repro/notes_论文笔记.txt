1　Image Super-Resolution Using Deep Convolutional Networks (SRCNN)
一：
创新：
1.将深度卷积神经网络CNN运用到单图像超分SR上，并且效果显著相比于传统的方法
2.不需要任何预处理/后处理
工作：
增加非线性层，使用更大的滤波器尺寸（e.g.3*3,5*5,7*7）
可以同时处理RGB三色通道
扩展测试图像集发现效果依然比当代方法效果更好
二：
现有的四种方案概述，且主要侧重单通道或灰度图像，对于RGB的较少
当时的深度学习和图像领域的结合主要是用于去噪，且使用的是MLP（全连接层FC），并未出现使用卷积层这一方法
三：
卷积神经网络的公式运算
和基于稀疏解码的联系：本质上稀疏解码也是一种卷积神经网络，存在卷积运算加上非线性化运算
本方法优化的是包含所有操作的端到端的映射（即优势在于不再人工对patch进行标注的方法：传统的是通过patch提取特征->低分辨率字典编码->高分辨率重建->patch重合，但是每个模块都是独立设计的，最终融合；但是本方法则是：输入低分辨率图片->经过CNN，这其中参数的自己的迭代学习都不再需要人的干预->输出高分辨率图片，实现直接从输入到学习到输出）
损失函数LOSS：均方误差：MSE (但其实使用其他的评估指标SSIM,MSSIM结果依然不错，比传统的方法要好)
权重的更新则是梯度下降：（在卷积层中不使用填充避免边界效应）
四（结果验证）：
滤波器尺寸越大，效果越好
CNN的层数和效果表现不呈正相关特性
局限：学习率参数的设置难以满足克服陷入局部最小值的问题（ps：这篇文章有点久远，现在解决的方法较多，比如随机梯度下降+动量增量的设置，或者Adam，AdamW的使用自适应学习率）
和最前沿的一些方法使用同样的评估方法的比较，本方法在部分评估下的得分上领先
2　SRFormerV2: Taking a Closer Look at Permuted Self-Attention for Image Super-Resolution
摘要：基于transformer的图像超分模型（e.g.SwinIR）的窗口尺寸可以显著增加模型性能，但是问题是窗口越大计算开销越大，对此，本文提出了SRFormer可以减少计算负担，并且在同等数据集上还有更好的效果PSNR=33.86dB
一：
图像超分方法：残差学习，密集连接，通道注意力机制（本文所用）
本文提出了PSA（排列自注意力机制）
提出缩减键和值矩阵的通道维度，并采用排列操作将部分空间信息传递到通道维度中。这样一来，尽管通道数量减少了，但空间信息不会丢失，每个注意力头也能保留适当数量的通道以生成具有表现力的注意力图
二：
介绍了CNN的图像超分的最近相关研究，还有基于Transformer架构的简要概括，并说明本文并不是直接利用自注意力来构建模型，而是针对自注意力机制本身，研究在不增加参数数量和计算成本的前提下提升超分性能
三：
3.1 总体架构
整体架构由三部分组成：像素嵌入层（一个3×3卷积，将低分辨率图像转换为特征嵌入）、特征编码器（由N个排列自注意力组构成，每个组包含M个排列自注意力块，其后紧跟一个3×3卷积）、以及高分辨率图像重建层（包含一个3×3卷积和一个子像素卷积层）。
模型通过计算高分辨率重建图像与真实高分辨率图像之间的L1损失来优化。
3.2 排列自注意力块（PAB）
核心是置换自注意力（PSA） 和卷积前馈网络（ConvFFN）。
PSA机制：给定输入特征图和缩减因子 r，首先将特征图分割成不重叠的窗口。然后通过线性层获取Q、K、V，其中Q保持通道维度不变，而K和V的通道维度被压缩至 C/r^2。随后，将K和V中的空间令牌转移到通道维度（即置换操作），得到置换后的令牌。使用Q以及压缩后的K、V执行自注意力计算，同时引入相对位置嵌入。PSA的关键在于：它允许更多令牌参与自注意力计算，而不增加计算成本，且每个注意力头能保留足够通道以生成具有表现力的注意力图。
ConvFFN：在FFN块的两个线性层之间加入一个局部深度卷积分支（如5×5深度卷积），以帮助编码更多高频细节，补偿自注意力机制导致的高频信息损失。
3.3 大窗口自注意力变体
文档介绍了另外两种大窗口自注意力变体，与PSA进行对比： 
令牌减少：通过深度可分离卷积对K和V的令牌数量进行下采样，减少计算量，但会导致空间信息丢失。
令牌采样：从每个窗口中随机采样部分令牌用于K和V。这种方法会丢失场景内容的结构信息，性能较差。
实验表明，PSA的性能优于这两种变体。
四：通过结合上述三种增强方法（扩大窗口尺寸、增加通道数量、引入局部小窗口模块），将SRFormer升级为SRFormerV2，从而在计算成本相近的情况下，显著超越了此前的最先进模型HAT。此外，还设计了一个计算成本更低的版本SRFormerV2-S，依然能实现与HAT相当的性能。
五（实验）：
验证得到当且仅当深度卷积核尺寸为5*5时，ConvFFN这种效果最佳
缩减率r：当窗口尺寸在48以内时，我们发现较大窗口带来的性能提升要优于通道压缩所造成的损失。然而，进一步增大窗口尺寸（例如，比较40、r = 2与80、r = 4的情况）则会导致性能下降
在图像去噪，压缩伪影减少，图像去模糊这些方面与其他方法在相同的多个数据集和同一特殊参数比较性能差异均优异，同时又对于真实世界图像和分布外数据集做了一定的测试，泛化能力还不错
3　SRConvNet: A Transformer-Style ConvNet for Lightweight Image Super-Resolution
创新：提出了傅里叶调制注意力机制：模拟多头自注意力机制，并提出动态混合层DML合了通道分割与混洗操作之间的多尺度动态卷积机制，从而更好地聚合局部特征表示
FMA：相比于传统CNN网络，CNN主要通过固定大小的卷积核在空间域进行特征提取，例如3×3卷积只能关注局部区域，因此对于图像中距离较远但具有相似关系的区域，CNN需要经过多层堆叠才能建立联系。FMA通过傅里叶变换，将空间域特征转换到频域中进行学习。由于频域信息能够描述图像整体结构和不同频率成分，因此可以捕获空间中距离较远区域之间的关系。例如图像中两个空间位置较远但属于同一类别的物体区域，在频域中可能具有相似的频率特征，因此模型能够学习它们之间的关联。通过频域信息和空间域特征的融合，FMA增强了CNN对全局信息的感知能力，使其能够实现类似Transformer Attention的长距离依赖建模能力，同时保持较低的计算复杂度。
DML：DML主要提出动态卷积机制，相比传统CNN中固定卷积核的方式，DML能够根据输入特征动态调整不同卷积尺度的信息贡献。具体来说，DML同时利用多个尺度卷积分支（例如5×5和7×7卷积）对输入特征进行提取，然后根据当前输入特征学习不同尺度卷积结果之间的融合权重。例如，对于纹理较复杂的区域，网络可能提高小尺度卷积特征的比例，以获取更加细致的信息；对于结构较大的区域，网络可能提高大尺度卷积特征的比例，以获得更加完整的上下文信息。因此，DML并不是直接选择某个卷积核（例如选择5×5或者7×7），而是让多个卷积尺度共同参与，通过学习不同尺度特征的重要程度，实现更加灵活的局部特征提取。
4　Progressive Focused Transformer for Single Image Super-Resolution
(CCF A)
一：
三种注意力机制：普通注意力，稀疏注意力（自动过滤权重较低的影响），渐进式聚焦注意力机制（本文的方法：将孤立的注意力图连接起来，利用注意力权重跳过不必要的计算，从而更好的聚合相关标记）
卷积CNN存在的问题就是他只能关切到局部特征信息（有效感受野虽然可以扩大但是只是相邻的信息，相对而言transformer则可以有效利用长距离依赖关系提升图像中的细节恢复效果）。
自注意力机制的缺陷：计算复杂度呈二次方增长，同时为获得高质量超分结果，法1：扩大窗口尺寸；法2：设计精巧的加权策略。
本文创新：建立了相邻层之间的注意力图谱关联，并提出渐进式聚焦注意力PFA（优势：1.提升重要令牌的权重并且抑制不相干令牌的权重，继承前一层的注意力权重。2.计算预筛选能力。
然后将PFA应用到PFT，在最大窗口下保持模型效率
二：主要回顾了基于Transformer的超分辨率技术以及具有稀疏注意力的Transformer方法。在超分辨率方面，现有方法从传统CNN逐步转向Transformer，如IPT、SwinIR、CAT、HAT、ATD、IPG等，利用自注意力机制扩大感受野、增强特征交互，但仍面临计算复杂度和无关特征干扰的问题。在稀疏注意力方面，NLSA、ART等方法通过稀疏化权重来聚焦相关特征，然而它们仅在单层内进行筛选，未能利用跨层信息。本文提出的PFT方法正是针对这些不足，通过渐进式聚焦注意力（PFA）将相邻层注意力图关联起来，在前层指导下过滤无关标记并降低计算量，从而实现更高效的特征聚合
三：
通常情况会采用稀疏注意力来减轻无关特征的负面影响，常用的方法有top-k选择，然后在进行softmax
PFA的特点：利用前一层的注意力图，对于各层始终保持相似性的高度相关词元的权重加强，同时可以识别无关特征，减少计算开销。
这里的乘法不是为了简单降低数值大小，而是为了实现一种“连续关注增强”的效果。如果某一个 token 位置在连续多个 Transformer 层中都具有较高的重要性，那么经过多次相乘后，该位置的权重会持续增强；反之，如果某个位置只是偶然在某一层中获得较高响应，但是之前层认为它并不重要，那么它的最终权重会被逐渐抑制。因此，经过多层传播以后，Attention 会逐渐集中到真正与当前恢复目标相关的区域。
在得到融合后的 Attention Map 后，作者进一步引入 Top-k 策略生成 Attention Index，也就是选择每一个 Query 对应的最高相关性的 k 个 Key。例如，如果一个 Query 原本需要关注1024个token，那么经过上一层 Attention 的筛选后，它可能只保留其中128个最相关的位置。这里需要注意，Top-k 并不是简单地把 Attention 数值变成0和1，而是生成一个索引矩阵，用于告诉下一层哪些 Query-Key 关系需要计算，哪些关系可以跳过。因此，PFA真正减少的不是输入 token 的数量，也不是 Query 或 Key 的维度，而是减少了 Attention 矩阵中需要计算的连接数量。
为了进一步降低计算量，作者提出 Progressive（递进）的机制。所谓递进，并不是说图像 token 数量随着网络深度减少，而是说每一层允许一个 Query 查看的位置逐渐减少。假设一个窗口最开始有1024个token，那么第一层可能允许 Query 与全部1024个Key进行匹配；下一层根据上一层结果，只保留其中一部分重要区域，例如512个；再下一层进一步缩小到256个。这个过程类似于人眼观察图像的过程：第一次观察时需要看整张图像，确定目标的大概位置；第二次观察时集中到目标区域；第三次观察时进一步关注局部细节。因此，PFA通过层间 Attention 信息传递，使 Transformer 从“全局搜索”逐渐变成“局部精细搜索”。
输入低分辨率图像后，首先通过浅层卷积提取基础特征，然后经过多个包含 PFA 模块的 Transformer Block 进行深层特征提取，最后通过上采样模块恢复高分辨率图像。与传统 Transformer 不同的是，PFT 中每一个 Transformer Block 不再独立计算 Attention，而是通过上一层产生的 Attention Index 引导下一层的稀疏 Attention 计算，从而在保证长距离依赖建模能力的同时降低计算复杂度。

5　CATANet: Efficient Content-Aware Token Aggregation for Lightweight Image Super-Resolution
摘要：基于Transformer的方法在低层视觉任务中表现优异，例如图像超分辨率(SR)。然而，其计算复杂度会随着空间分辨率的提高而呈平方级增长。一系列研究试图通过将低分辨率图像划分为局部窗口、轴向条纹或膨胀窗口来缓解这一问题。图像超分辨率通常利用图像中的冗余信息来进行重建，而这种冗余不仅存在于局部区域，也存在于远距离区域。然而，这些方法将注意力计算限制在与内容无关的局部区域内，从而限制了注意力机制捕捉远距离依赖关系的能力。为解决这些问题，我们提出了一种轻量级的“内容感知令牌聚合网络”(CATANet)。具体而言，我们设计了一种高效的内容感知令牌聚合模块，用于聚合远距离且内容相似的令牌;该模块在所有图像令牌间共享令牌中心，且仅在训练阶段对其进行更新。随后，我们利用组内自注意力机制来实现远距离信息交互。此外，我们还设计了组间交叉注意力机制以进一步增强全局信息交互。实验结果表明，与目前最先进的基于聚类的方法SPIN相比，我们的方法取得了更优的性能:PSNR值最高提升了0.33dB，推理速度也几乎提升了一倍。
二：
注意力机制比CNN有更好的提取长距离特征
三：
CATANET：先用卷积获得基础视觉特征，然后通过多个残差组堆叠 TAB，在 TAB 内利用 CATA 根据内容自动组织 token，再通过 IASA 实现语义区域内部的长距离建模，通过 IRCA 借助 token center 实现不同语义区域之间的信息交换，最后恢复高分辨率图像。
TAB token聚合块：主要是为了实现内容相似的词元之间的精细的信息交互，但是SPIN和BOAT都存在推理速度较慢的问题，对此TAB由四个模块组成来解决这个问题：
①内容感知令牌聚合CATA：首先通过平均池化初始化token center，得到初始的视觉特征原型，然后对于每一个token计算其与各个token center之间的相似度，将token分配到相似度最高的center对应的group中。完成分组后，对每一个group内部的token进行平均，得到新的center c_j'，用于表示该group当前真正的内容特征。为了避免center在训练过程中发生剧烈变化，采用EMA（指数滑动平均）对center进行更新，使其从历史center逐渐向当前group特征方向靠近：其中λ取0.999。随着训练过程不断进行，token center逐渐学习并稳定表示不同类型的视觉内容。最后，由于不同group包含的token数量不同，会导致后续attention计算难以充分利用GPU并行能力，因此对于token数量较多的group进一步划分为固定大小的subgroup，以提高计算效率。
②组内自注意力机制IASA：由于CATA得到的每一个group包含的token数量不同，为了提高GPU并行计算效率，将较大的group进一步划分为多个固定大小的subgroup S。然后在subgroup内部进行自注意力计算，通过Q与K,V之间的匹配，使同一内容组内的token能够进行信息交互。同时，由于一个group可能被划分到多个相邻subgroup中，为避免同一语义内容被切断，IASA允许当前subgroup的Q关注相邻subgroup的K,V，从而增强同一group内部的长距离依赖关系。
③组间交叉注意力IRCA：由于IASA只能实现同一个group内部token之间的信息交互，而不同group之间缺少联系，因此引入token center作为全局信息表示。通过将group内token作为Query，将所有token center作为Key和Value，使每一个group能够查询其他group的全局语义信息，从而实现不同group之间的信息交流，增强整体特征的全局建模能力。

6　MAT: Multi-Range Attention Transformer for Efficient Image Super-Resolution（IEEE TCSVT 2025）
摘要：Transformer 超分性能优异，但为扩大感受野而增大自注意力窗口会带来计算复杂度二次方增长，且固定尺寸窗口限制有效感受野与中间特征多样性。本文提出多范围注意力 Transformer（MAT），将空洞卷积与自注意力机制结合，实现多范围注意力 MA 与稀疏多范围注意力 SMA，在不增加计算量下同时捕获区域特征与稀疏全局特征，并配合 MSConvStar 模块增强多范围表示学习。
一：
自然图像具有局部性和冗余性两个先验：相邻像素强相关，相似模式会在图像不同位置重复出现（自相似性）。因此重建既需要局部依赖，也需要非局部依赖，但并非所有全局依赖都有价值——例如重建人脸的一只眼睛时，另一只眼睛能提供有用的非局部参考，而皮肤、背景等平滑区域意义不大。传统窗口自注意力WSA 固定窗口大小，无法建模不同空间尺度的层次特征，扩大窗口又带来二次方复杂度。本文正是要高效、灵活地捕获多空间范围特征。
创新：
1. 提出MA和SMA两种互补机制，灵活捕获多范围区域特征与稀疏全局特征。
2. 提出MSConvStar模块替代传统前馈网络FFN，融合多尺度卷积与star操作。
3. 提出MAT整体架构，轻量与经典两个版本均以更少参数、更低计算量超越SOTA。
二：
简要回顾 CNN 超分（固定卷积核、局部感受野受限）与 Transformer 超分（窗口自注意力扩大窗口计算量二次方增长），以及层次特征表示相关工作，指出固定窗口无法灵活整合多尺度信息的问题。
三：
多范围注意力 MA：类似卷积的邻域注意力（RA），把每个像素的注意力限制在 k×k 邻域，再扩展到多个不同范围 k1…kn（7×7、9×9、11×11），不同注意力头关注不同范围，克服 WSA 固定窗口划分的限制。
稀疏多范围注意力 SMA：借鉴空洞卷积思想，在注意力区域打孔（dilation rate δ），用同样数量的 key/value 覆盖更大的空间范围（kd = k + (k-1)(δ-1)），实现稀疏全局注意力，不增加计算开销。
MSConvStar：传统 FFN 是两层线性变换加激活，难以建模复杂层次空间关系；MSConvStar 融合多尺度深度卷积与 star 操作（逐元素相乘），在不增加网络宽度下实现非线性特征空间变换，增强 token 交互。
多范围依赖：LAB（深度卷积 + 通道注意力）负责局部依赖，MA 负责区域特征，SMA 负责稀疏全局信息，三层协同实现「局部—区域—稀疏全局」的多范围表示学习。
四：
轻量版 MAT-light 仅 714K 参数，Urban100×4 达 26.83dB；比 SRFormer-light 推理快约 3.3×、显存降 24%。消融显示 SMA 对扩大感知范围贡献最大，LAM/ERF 可视化也验证其感受野远大于对比方法。
7　A Lightweight Frequency-Selection-Based Progressive Patch Transformer Network for SISR（IEEE TCSVT 2026）
摘要：轻量超分中分治多路模型在性能与计算量间折中较好，但有两个局限：仅在空域解耦图像成分（平滑区、边缘、纹理）可能次优；无法显式建模全局依赖。本文提出频率选择渐进 Patch Transformer 网络（FSPPTN），在频域与空域分别渐进解耦恢复不同成分，并用一阶梯度引导的 patch 间自注意力显式捕获全局结构相似性。
一：
自然图像由平滑区、边缘、纹理等不同成分组成，各成分恢复难度不同。现有分治多路模型只在空域解耦成分、且无法显式捕获全局依赖。本文用频率选择（FEB）+ 空间恢复（SRB）渐进解耦，用梯度引导的 patch 间自注意力显式建模全局结构相似性。
创新：
1. 提出频率选择模块 FSM（频率增强分支 FEB + 空间恢复分支 SRB），在频域和空域分别渐进解耦恢复不同图像成分。
2. 提出轻量多分支梯度引导 patch 间自注意力 MGIPSA，用一阶梯度把 patch 结构信息压缩到低维，显式建模全局结构相似性。
二：
回顾轻量单路模型（CNN、Transformer、Mamba 均无法显式捕获全局依赖）与分治多路模型（仅在空域解耦），指出空域解耦次优与全局依赖缺失的问题。
三：
频率增强分支 FEB：借鉴短时傅里叶变换（STFT）思想，用窗口化 FFT 精确提取局部频域特征，配合可学习权重矩阵动态决定「哪些成分当前层恢复、哪些增强后传深层」；加法连接得到增强成分、减法连接得到残差成分。
空间恢复分支 SRB：多尺度深度卷积提取上下文，多门控机制（patch 平均池化 + 简单门控 + patch 门控）实现 patch 级整体信息与像素级特征的跨粒度交互。
渐进式恢复：多个 FSM 逐层解耦：浅层恢复轮廓、平滑区（低频），深层恢复纹理、边缘（高频），与图像成分特性相符。
多分支梯度引导 patch 间自注意力 MGIPSA：对每个 patch 计算水平垂直方向一阶梯度绝对值之和，把结构信息压缩到低维 patch 级统计量，再在 patch 间做自注意力，显式捕获整幅图的全局结构相似性且大幅降计算量；多分支策略（shift window 多起始位置）增加 patch 多样性。
四：
×4 比 MaIR-Small 在 Manga109 高 0.14dB，参数少 48.3%、FLOPs 低 63.5%；比 MambaIRv2-light 参数少 10.1%、FLOPs 低 34%。
8　Dual-Domain Modulation Network for Lightweight Image Super-Resolution（IEEE TMM 2026）
摘要：现有频率超分方法难以平衡整体结构与高频细节：傅里叶域方法高 PSNR 但高频纹理模糊，小波域方法纹理清晰但整体结构受限。本文提出双域调制网络 DMNet，在小波域重建特征、在傅里叶域做监督，同时利用小波与傅里叶信息。
一：
空域轻量超分感受野有限，需堆叠大量块导致效率低。频率方法中，傅里叶域调节全局频率分布可得到高 PSNR 但高频纹理模糊；小波域强调高频、纹理清晰，但各子带梯度方向不一致、不利于损失控制，整体结构受限。本文结合二者优势。
创新：
1. 发现「小波特征 + 傅里叶监督」的混合频域方式能有效平衡整体结构与高频重建。
2. 提出小波域调制 Transformer WMT，突出高低频关系。
3. 提出空域调制 Transformer SMT。
二：
回顾轻量 SR 方法（空域为主，未利用频域）与频率 SR 方法（傅里叶或小波单一域，未结合二者优势）。
三：
小波域调制 Transformer WMT（核心 WMA）：通道降维后用离散小波变换 DWT 分解为 1 低频 + 3 高频子带，沿通道拼接，自注意力探索高低频子带关系（互补），动态卷积（大核组卷积生成动态权重）细化频率细节，IDWT 恢复。计算复杂度 O(C²N/4)，低于 Restormer 与 Wave-ViT。
空域调制 Transformer SMT（核心 SMA）：在通道上做自注意力，压缩通道隐式估计全局空域特征，以更低开销重建空域像素分布。
损失函数：空域重建 L1 + 傅里叶幅值相位 L1（λ=0.1），避免小波各子带梯度方向不一致的调参困难。
四：
PSNR 与 SRFormer、MambaIR 相当，但 FLOPs 不到其 50% / 60%，推理快 15.4× / 5.4×；LAM 显示 DI 更高、激活范围更广。
9　PromptSR: Cascade Prompting for Lightweight Image Super-Resolution（IEEE TMM 2026）
摘要：轻量 ViT 受窗口自注意力限制感受野有限，窗口二次复杂度制约大窗口。本文提出 PromptSR，将 prompt learning 引入轻量超分，核心是级联提示块 CPB，通过全局锚点提示层 GAPL 和两个局部提示层 LPL 增强全局信息访问与局部细化。
一：
窗口自注意力把 token 限制在固定窗口内，感受野受限；扩大窗口又二次方增长。本文借鉴 prompt 思想，构造锚点提示 AP 捕获全局先验，通过 AP 与像素跨空间交互实现高效长程连接。
创新：
1. 提出锚点提示 AP，利用自然图像跨尺度相似性捕获全局先验。
2. 提出级联提示块 CPB，级联 GAPL 与两个 LPL，以全局到局部、粗到细方式扩大感受野。
二：
回顾轻量 Transformer 超分（窗口注意力感受野受限）与 prompt learning（引入额外上下文引导模型），指出现有方法未能用提示解决窗口感受野受限问题。
三：
全局锚点提示层 GAPL：利用自然图像跨尺度相似性（线条等基本结构在不同尺度保持一致），用下采样特征作锚点 A，跨尺度 attention 构造低维锚点提示 P（数量 HW/d²，计算开销仅为全局自注意力的 1/d²）。分三步：锚点提示生成（粗相似度图）、锚点提示更新（组内更新保持多样性）、锚点提示（细相似度图，交叉注意力得到 Xp，为每个像素引入窗口外全局先验）。
局部提示层 LPL（两个）：结合窗口自注意力 WSA 与类别自注意力 CSA，利用 GAPL 的粗/细相似度图作额外全局提示，把相似 token 分类到不规则窗口做自注意力，实现粗到细的局部细化。
四：
PromptSR 仅 0.78M 参数与 12M 大模型相当；Urban100×4 比 OmniSR、HPINet 分别高 0.37dB、0.31dB；LAM 显示激活像素更多。
10　Structural Similarity-Inspired Unfolding for Lightweight Image Super-Resolution（IEEE TIP 2025）
摘要：数据驱动方法扩大感受野但复杂度上升；展开（unfolding）范式通过精巧模块保持紧凑。本文提出结构相似性启发的展开网络 SSIU，把一个受结构相似性约束的超分优化问题展开成网络，结合数据驱动与模型驱动优势。
一：
扩大感受野是把双刃剑：提升性能但增加复杂度。展开范式更通用、可解释。传统方法基于自相似/非局部相似表明，只有结构相似的远距离信息才对中心像素重建有益。本文据此把超分问题展开成逐步迭代的网络。
创新：
1. 提出 SSIU，稀疏激活远距离像素，以轻量架构提升超分。
2. 提出混合尺度门控模块 MSGM（稀疏 + 结构相似性约束）与高效稀疏注意力模块 ESAM（降低长距离建模复杂度）。
3. 提出基于混合专家的特征选择器 MoE-FS 融合多尺度特征。
二：
回顾 CNN、Transformer 与轻量超分方法，指出其专注网络设计而未显式建模超分重建过程。
三：
问题建模：
把超分建模为 MAP + 稀疏编码，加入结构相似性约束项 γ‖α-β‖₁，引入辅助变量 z，用半二次分裂交替求解，拆成 S1 稀疏约束、S2 结构相似性约束、S3 全局稀疏逆求解 + 中心化三个子问题。
混合尺度门控模块 MSGM：两个并行分支（1×1 卷积 / 1×1→深度卷积→1×1），GeLU 后逐元素相乘门控，动态调整权重，统一实现稀疏约束、结构相似性约束与特征聚合。
高效稀疏注意力模块 ESAM：max-pooling 稀疏采样 + 重叠块划分 + 标准自注意力 + 3×3 卷积 + 双线性上采样，只对结构相似区域做长距离建模。
混合专家特征选择器 MoE-FS：学习门控权重，融合编码块、瓶颈块、解码块三个阶段的输出特征。
四：
×4 Manga109 比 LBNet、CRAFT、ATD-light 分别高 0.76dB、0.25dB、0.12dB；推理时间与显存均为对比方法最低。
11　ASID: Efficient Attention-Sharing Information Distillation Transformer
针对 Transformer 超分自注意力堆叠导致计算量大的问题，把原本用于高效 CNN 的信息蒸馏结构改造后引入 Transformer，降低堆叠自注意力的计算负担；同时引入跨块注意力共享，进一步压缩自注意力开销。仅约 300K 参数即可达到与现有方法相当的性能。
12　Asymmetric content-aided Transformer
传统多头自注意力 MSA 各头独立重复计算，存在冗余且易丢失高频信息。本文把 MSA 扩展为非对称结构做增量式自注意力学习，并提出内容辅助位置编码 CaPE，让模型根据图像内容自适应调整相对位置关系，以更少参数、更低计算量超越同类轻量方法。
13　Cross-domain Aggregation Frequency Fusion Transformer
现有 ViT 超分只在空间或通道单一维度聚合、复杂度随尺寸增长且忽略纹理需求。CAFT 用空间域交叉探索注意力 SCEA 做跨高宽交互、通道域转置注意力 CDTA 做跨通道交互、频率引导融合块 FGFB 用频域提取细粒度纹理，三者结合实现全局关联与纹理重建。
14　Memory-efficient divide-and-conquer attention
多数轻量方法只关注速度或质量、忽视显存占用。MEDCA 用分治策略：沿通道把特征分成多个子空间，每个子空间分窗口再用非对称策略切成两部分分别自注意力，把子空间内空间复杂度降一半，同时扩大空间上下文，显著降显存并提升质量。
15　Single image SR with lightweight multi-scale dilated attention network
小卷积核感受野受限、大卷积核又引入冗余。MDAN 用多尺度空洞注意力：局部残差模块 LRM（蓝图可分离卷积）+ 全局注意力模块 GAM（多尺度空洞注意力 MDAB + 蓝图前馈网络 BFN），以轻量方式扩大卷积核并整合高低频特征。
16　Lightweight image SR with tokenized dynamic embedding network
提出自适应特征 token 化策略，有选择地提取关键 token 降低计算量；配合动态上下文嵌入注意力做高效长程依赖建模，以及双视角特征整合模块融合空间与上下文信息，兼顾细粒度纹理与全局一致性。
17　EchoSR: Efficient context harnessing for lightweight image SR
现有轻量方法扩大感受野要么开销大、要么简单放大卷积核、要么缺乏多尺度整合。EchoSR 把特征学习解耦为「局部→多尺度→全局」三阶段，用跨尺度重叠融合机制做无缝多尺度整合，比 SOTA 快约 2×。
18　Focus-guided feature fusion network（FocusSRNet，Neural Networks）
首次把图像焦点（清晰度）信息作为先验引导引入超分，由焦点测量单元 FMU、大感受野特征提取模块 LRFFEM、非对称通道特征增强模块 ACFEM 组成，增强特征表示的充分性与判别性。
19　Lightweight multi-scale distillation attention network（MSDAN，Knowledge-Based Systems）
提出有效分支融合块 EBFB（不同核尺寸像素注意力 + 蒸馏连接）提取多感受野特征，并提出增强多尺度空间注意力 EMSSA（AdaptiveMaxPool 多下采样分支），具备自适应空间信息提取能力并保持大感受野。
20　Toward lightweight SR via re-parameterized kernel recalibration
深度卷积按通道分段操作导致表达力下降。本文提出核重校准策略，把一个通道的核与其他通道参数关联，使核能关注先前被忽略的部分；渐进多尺度重校准块 PMRB 训练后重参数化为标准卷积，推理开销不变而性能提升，仅需主流方法约 1/3 计算量。
21　A lightweight hybrid neural network for remote sensing image SR
遥感超分模型大、计算复杂。用 Ghost 模块替换传统卷积构建轻量结构，高频滤波多蒸馏块提取高频细节，移位窗口 Transformer 捕获全局信息，最后特征融合上采样重建，降低参数与计算量。
22　A Collaborative Network of Mamba and CNN
提出 Mamba 与 CNN 协同的轻量超分网络，协同单元 CUMC 用 Mamba 的全局感受野与线性复杂度做长距离建模，用 CNN 的归纳偏置做局部交互补偿，同时利用非局部与局部先验；多尺度空间细化注意力 MSSRA 调制通道权重、聚合跨尺度特征。
23　Lightweight image SR network based on dynamic graph message passing and convolution mixer（GMN，ESWA）
现有模型仅在图像空间提取特征、难捕获长短依赖。图混合块 GMB 融合动态图消息传递 DGMN（长程结构化关系、自适应采样节点）与卷积 mixer ConvMix（通道 + 空间混合），兼顾全局图结构与局部模式。
24　Lightweight image SR method inspired by memory consolidation
受记忆巩固机制启发，再激活特征架构 RFA：全局逆序逐层组织记忆再激活块 MRB 做全网特征巩固，局部级联记忆激活块 MAB 构造双向处理通路，用宽感受野深层特征再激活浅层细节；配合记忆变异性增强注意力 MVEA 与多源记忆整合注意力 MMIA，比 HSRNet 在 Urban100×4 高 0.32dB 且参数少 34.4%。
25　Convolution mixer-based transformer-style network for lightweight remote sensing SR（CMTSNSR）
遥感图像结构复杂、纹理多样、末端上采样易丢细节。以线性复杂度卷积调制 Conv2Former 为基础，卷积 mixer 混合空间与通道（空洞深度卷积扩大感受野 + 深度卷积混合空间 + 逐点卷积混合通道），比 Rep-Mamba 快约 2.1×。
26　Deep learning-based remote sensing image SR: Recent advances and challenges（综述）
系统综述 2020 年以来深度学习遥感超分：有监督方法按 CNN、注意力、GAN、Transformer、扩散模型、Mamba 六类划分，无监督按自监督、对比学习、零样本、生成式四类划分，并梳理数据集、损失函数与评估指标，总结趋势与挑战。
27　Training-Free Model Ensemble for SISR via Strong-Branch Compensation
针对多个预训练模型如何免训练融合输出的问题，提出双分支输出级集成：HAT 提供稳定主重建，MambaIRv2 几何自集成提供高频细节补偿，在图像空间做轻量加权融合，不更新参数、不引入可训练模块，低开销升级现有系统。
