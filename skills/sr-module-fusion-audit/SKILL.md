# 轻量超分模块融合审查

目标是在用户指定骨架、预算和授权范围内获得可复现收益。Skill是可维护的工作规则，不是模型自我训练，也不保证PSNR上涨、永不出错或顶会录用。

## 先确认任务与证据

- 按用户本轮要求选择讨论、诊断、实现、实验或结果审查；收到经验或结果不等于获准训练、改模型、发消息或操作其它服务器。
- 读取工作区AGENTS、研究经验、实验SOP和当前候选卡。先核实用户指定branch/commit、实际forward、loss和已知正负证据；保护未提交改动。新候选沿项目规定独立分支，不覆盖骨架。
- LFMN/V1或N21–N23任务先读[项目参考](references/lfmn-v1.md)。其它项目不套用该参考的模型名称、设置和数值。
- 建立来源表：代码事实、已验证实验、用户提供但未审计结果、论文结论、待验证假设。未知字段明确写未知；借鉴论文时核原文和适用范围，不把其它网络的提升当移植保证。

## 明确新增信息，再选择融合

用一条可证伪链说明：可观察问题 → 可能原因 → 新增的任务相关信息/能力 → 作用位置 → 可测机制 → 泛化与资源预测。名字不同、图好看、代理指标变好都不足以证明互补。

先核实旧机制已经做什么，区分权重迁移和随机初始化的结构借鉴。只在诊断支持时选Adapter、归一化变化、辅助loss、分组学习率、warmup或裁剪；不是必须一起添加的套餐。

选择有依据的最小增加或替换；保留廉价融合对照的实现可能性。相加须同表示且无意外广播，concat后投影须算成本，乘法须查幅值压缩；cross attention明确Q/K/V方向与Nq×Nk成本。低相关不保证有用，高相关不保证冗余。不以“替换更创新”“参数更多更强”或“审稿人喜欢”作为依据。

## 接口与状态检查

至少交付一个接口表，包含shape/layout、H/W/token顺序、像素对应、dtype/device、数值范围、归一化轴、mask/padding/crop、状态生命周期与梯度路径。

- 不能靠任意reshape、广播或1×1投影掩盖空间错位；验证奇数尺寸、长宽不等及窗口不可整除的样本。
- 画清局部/模块/全局残差和写回位置。确认新增输出是修正量还是已包含输入，避免重复残差；统计幅值、gate分布、异常值仅作诊断，不作收益证明。
- 不机械删除相邻归一化/激活。不认为两个LN一定冲突或BN一定该删；核统计轴、train/eval状态与预训练原映射。
- 参数、buffer、离散标签和持久状态分别命名。明确初始值、何时重置/更新、detach点、batch及图像依赖；不要复制旧forward导致骨架机制丢失。
- 超参数按语义迁移：整除/合法性、比例起点、感受野、成本及需验证参数分开。通道减半不意味着窗口、头数、rank、温度、学习率或loss权重全部减半。

## 检验学习启动，而非只检验代码运行

在授权的廉价工程验证中检查：实际调用与最终损失连通、有限输出/损失/梯度、新参数在optimizer中无重复遗漏、预期buffer更新、真实参数更新及严格保存重载。

- 零初始化注明具体位置。零gate可能使内部首步梯度为零；不能把整个乘积/残差路径同时置零后假定可启动。允许解释清楚的暂时零梯度，检查后续是否启动，不用“208个参数有梯度”等数字代替性能。
- 报告checkpoint的missing/unexpected/手工过滤项及键数、参数元素覆盖率；不能把strict=False当所有shape不匹配自动跳过。
- AMP诊断检查反缩放和overflow跳步；冻结参数不等于停止状态更新。热启动、从零、续训分开，并给同起点/同额外预算对照。
- 优化诊断同时看组大小、梯度、参数范数和实际更新；不按原始梯度L2机械调学习率。改变训练策略与结构结果分别归档。
- 小批量拟合仅证明基本学习能力。同权重eval旁路仅检验该checkpoint依赖，不能替代独立训练消融，更不能把关闭机制后改善包装成候选成功。

## PSNR与基线复用闸门

复用必须核协议指纹：数据/退化/range、倍率、HR patch、有效batch、随机流/增强、初始化/预训练、optimizer/LR、scheduler完整时间轴、epoch及更新数、loss/teacher/EMA、源码与环境、评测代码。

SR指标另核RGB/Y、rgb_range、量化、边界裁剪、PSNR/SSIM实现、整图/chop/自集成、checkpoint选择。T_max150的前20轮不等于T_max20完整余弦。只有三位小数日志或缺逐图不能支持千分之一dB归因。公共修复同时作用对照与候选；已证明训练不受影响的旧权重可在获准审计后统一重评，旧口径曲线不能直接复用。

主问题是“新组合是否超过固定骨架”，不是是否超过更弱历史基线。先按项目SOP做最小主对照，整体通过后再补必要消融/多seed/外测，不强制一开始支付全部消融。若用户仅授权单组收集，记录基线待补，不作GO或相对提升声明。

按预注册固定epoch/末若干轮、逐图均值/中位数/胜率、按图片bootstrap、SSIM与统一资源比较，不挑best或事后删图。单seed的图片CI不证明跨训练seed稳定性。0.01/0.05dB不是自动显著；阈值来自该协议波动和预算。样本、倍率和结果范围不能扩大。

短筛失败/灰区按停止线处理，不靠延长长训或叠模块掩盖问题。慢收敛只有在有证据且有预注册/重新授权预算时复查。前期领先最终持平应考虑收敛效率，不冒称最终精度提高。

## 实现成本与服务器检查

报告实际完整路径参数、MAC/FLOPs计数覆盖、统一设备/尺寸/精度下warmup、同步延迟、peak allocated/reserved与缓存驻留。小参数、低维或线性表达不保证快；计算投影、排序、gather、布局、构图和多尺度转换。未知FLOPs不编造。

训练启动前检查日志是否触发dirty检查、输出拒覆盖、数据/权重存在、GPU占用、依赖版本、后台与关机授权。检查脚本的确定性能力不兼容不得误写为模型性能失败：仅已解释能力限制可采用诊断替代并报告CPU/GPU证据范围；其它错误仍阻断，不改生产训练来掩盖报错。不随意升级环境、关闭TLS验证或删除失败记录。

## 收到新结果时更新经验

每轮给出：问题与改动 → 证据与未知 → 准确协议/来源 → 结果与成本 → 继续/停止理由 → 下一项最小动作。

新增经验先追加项目实验记录，保留原始日志/权重hash/来源指针；总结成条件化规则，禁止将单个负例写成整个方法族失败或普遍禁用模块。获用户授权后更新此Skill和必要项目参考，验证并按项目要求commit/push。不要每次自动改全局skill、扩大权限或承诺更新后必然涨点。以减少重复失误、提高可复核性衡量经验价值。
